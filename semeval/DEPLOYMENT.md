# Deploying Semeval to Render (Render.com)

This guide walks you through deploying the production-grade **Semeval** platform to [Render](https://render.com) using the included `render.yaml` Blueprint.

---

## 🏗️ Architecture on Render

When deployed via `render.yaml`, Render automatically provisions:
1. **`semeval-db`**: PostgreSQL 16 database instance (with `pgvector` extension).
2. **`semeval-redis`**: Managed Redis 7 instance for background ARQ job queue & SSE pub/sub.
3. **`semeval-backend`**: Python 3.12 FastAPI web service running Uvicorn.
4. **`semeval-worker`**: ARQ background task worker process.
5. **`semeval-frontend`**: React + TypeScript SPA static site with automatic SPA routing rewrites.

---

## 🚀 Step-by-Step Deployment Guide

### Step 1: Push Repository to GitHub or GitLab
Ensure your code is pushed to your Git repository (GitHub or GitLab).

### Step 2: Connect Render Blueprint
1. Log into your [Render Dashboard](https://dashboard.render.com).
2. Click **New +** → **Blueprint**.
3. Connect your Git repository.
4. Select the repository and point to `semeval/render.yaml` if prompted.
5. Render will automatically parse the services defined in `render.yaml`.

### Step 3: Configure Environment Secrets
In the Render dashboard under service environment settings, fill in your API credentials:
- **`OPENAI_API_KEY`**: Your OpenAI API Key (`sk-proj-...`).
- **`ANTHROPIC_API_KEY`** *(Optional)*: Your Anthropic API Key (`sk-ant-...`) for automatic LLM fallback.
- **`DISABLE_AUTH`**: Set to `false` for production auth enforcement.
- **`JWT_SECRET`**: Auto-generated by Render blueprint (or set a custom 64-character secret).

### Step 4: Run Initial Database Migrations
The blueprint automatically runs `alembic upgrade head` during the build step of `semeval-backend`.
To verify migrations manually from Render Shell:
```bash
alembic upgrade head
```

### Step 5: Verify Deployment Health
Once the build completes:
- Backend Health Probe: `https://semeval-backend.onrender.com/api/v1/health` → `{"status": "ok", "version": "0.1.0"}`
- Swagger API Docs: `https://semeval-backend.onrender.com/docs`
- Frontend App: `https://semeval-frontend.onrender.com`

## 🔐 Production Checklist

- [x] `ENVIRONMENT=production`
- [x] `DISABLE_AUTH=false`
- [x] Pinned model versions (`gpt-4o`, `claude-3-5-sonnet-20241022`)
- [x] SSL enabled by default on Render domain endpoints
- [x] CORS restricted via `CORS_ORIGINS`
- [x] Automatic database backups enabled in Render PostgreSQL settings
